# Community-Led Growth for B2B SaaS

## Project Overview
This is a research project focused on Community-led growth for B2B SaaS. It aggregates and synthesizes insights to uncover actionable strategies for building and leveraging communities in the B2B context.

## Methodology
To ensure high-signal, practical insights over generic theory, 10 expert operators and founders were carefully chosen for this research. Their recent talks, podcasts, and social media posts serve as the primary dataset.

## Technical Stack
Data was aggregated and processed using:
- **Node.js** for automation scripts.
- **Supadata API** for YouTube video text/transcript extraction.
- **Automated JSON Parsing** for extracting and organizing LinkedIn content from raw data scrapes.

## Directory Structure
- `/research/sources.md`: List of primary sources.
- `/research/linkedin-posts/`: Parsed LinkedIn posts categorized by author.
- `/research/youtube-transcripts/`: Extracted YouTube transcripts.
- `/research/other/`: Miscellaneous research materials.
- `/scripts/`: Automation scripts for fetching and parsing data.
